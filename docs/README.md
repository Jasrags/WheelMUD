# Documentation

Two trees live here:

## `CODEMAPS/` — architecture maps for AI context

Token-lean (≤1000 tokens each) summaries of the codebase, regenerated by
`/update-codemaps` after major slices land.

| File              | Scope                                                       |
| ----------------- | ----------------------------------------------------------- |
| `architecture.md` | Layer diagram, boot flow, per-connection lifecycle          |
| `commands.md`     | Command catalog, registration pattern, auth gating          |
| `data.md`         | Tables, migrations 0001–0011, repo + creature/currency map  |
| `dependencies.md` | go.mod direct + indirect deps, build/runtime tooling        |
| `telnet.md`       | Protocol parser, session, mode stack, color/wrap, IAC       |

The `.reports/codemap-diff.txt` file at the repo root records what changed
between regenerations.

## `reference/` — game-system reference

Markdown ports of the Wheel of Time RPG rules used by the game logic
(abilities, classes, backgrounds, combat, equipment, feats, encounters,
etc.). The PDF source (`Wheel-of-Time-RPG.pdf`) lives one level up in
`docs/` for cross-reference.

These files are read by humans designing zones, mobs, and feats — they
are not loaded at runtime.
