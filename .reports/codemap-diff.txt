## New Subsystems

1. **Scheduler & Ticks** (internal/tick/)
   - 1 Hz heartbeat goroutine, named buckets (Save default 30s)
   - Subscriptions for each bucket drain safely in shutdown

2. **Persistence Manager** (internal/persist/)
   - Autosave manager with SaverFunc registrations
   - Called on bucket.Save pulses (default 30s) + shutdown (5s budget)
   - Currently saves: last_played_at via savePlayTimes()

3. **Event Bus** (internal/eventbus/)
   - Typed pub/sub: PlayerEntered / PlayerLeft from world events
   - Used by move commands to trigger room-based events

4. **Session Registry** (internal/session/)
   - Process-level bind/unbind tracking (account -> session mapping)
   - Enables multi-connection awareness: who, tell, channel dispatch
   - Compare-and-delete unbind prevents stale teardown from clobbering takeovers

5. **Panic Recovery** (internal/safego/)
   - Goroutine wrapper (safego.Go) with built-in recover + logging
   - Wraps shutdown-watcher, accept loop, per-session goroutines, shutdown drain
   - LOG_LEVEL env var (debug|info|warn|error) controls global slog level

6. **Creature Models** (internal/creature/)
   - Core stat block (abilities, HP, defenses, saves, speed)
   - Affects + stat mods (stubs for section 12 buffs/debuffs)
   - MobTemplate / MobInstance / Character type skeletons (full impl in 0009)

7. **Currency Type** (internal/currency/)
   - 4-denomination Amount (cp/sp/mk/gc at 1/10/100/1000 ratio)
   - Parse / Format / In / Add / Sub with overflow guards

## Session Enhancements

- **LastTellFrom**: Tracks most recent tell sender for reply convenience
- **LastInputAt**: Stamped on every command, used for idle detection (who >= 30s)
- **channelMuted**: Crossmu-guarded bitmask (channel_id -> muted boolean)
- **SetChannelMuted / IsChannelMuted / ToggleChannelMuted / ChannelMutedSnapshot**: Helpers for atomic mutations

## Architecture Changes

1. **Startup**: Now boot scheduler → load channels → build registry (with dynamic channel cmds) → start autosave loop
2. **Shutdown**: Drain sessions (10s) → autosave final pass (5s) → stop buckets/scheduler/bus
3. **Per-connection**: readLoop + runDispatcher still the same, but writeMu now shared with any future emitter
4. **Auth flow**: AuthLevel (Guest/Player/Admin) checked at Registry.Dispatch time, not mode entry; enables guest help, progressive privs
