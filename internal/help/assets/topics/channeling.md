title: Channeling the One Power
keywords: weave, weaves, saidar, saidin
---
Channelers draw on saidar (women) or saidin (men) to weave the One
Power. A weave declares an element mix (Air/Earth/Fire/Spirit/Water),
a slot level, and a target. Slot levels gate which weaves a given
channeler can hold ready.

Channeling is partially scaffolded: the creature/channeling tables
exist (migration 0008) but the weave list, slot bookkeeping, and
the round-tick that actually resolves a weave are still pending —
see ROADMAP.md §12 / Phase D.

Note: this is the in-world *channeling* topic. For chat channels
(say/yell/clan/etc.) see {{help channels}}::cyan.
